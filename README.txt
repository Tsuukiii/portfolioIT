# Portfolio — Mohamed Baha Eddin Drira

Ce dépôt contient un site portfolio statique (HTML/CSS/JS) moderne, responsive et animé.

## Configuration
- **Lien Indeed** : ouvrez `index.html` et remplacez la valeur de `INDEED_URL` par votre lien Indeed.

## Déploiement rapide
- **GitHub Pages** : poussez ces fichiers dans un repo, activez *Settings → Pages* (branche `main` / racine).
- **Netlify** : glissez-déposez le dossier dans l'interface Netlify (Build: none, Publish directory: `/`).
